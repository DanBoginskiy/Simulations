# Допуски тестів

Цей файл написано **до першого запуску тестів** (2026-11-06) і після запуску не послаблювався.
Якщо тест не проходить — це знахідка, яку треба пояснити, а не привід розширити допуск.
Кожен допуск має під собою оцінку з теорії: що саме очікуємо і з яким запасом.

Позначення: `h` — крок, `N` — кількість кроків, `ΔE/E₀` — відносна зміна енергії.

## 1. Гармонічний осцилятор `x″ = −ω²x`

Умови: `ω = 1`, `x₀ = 1`, `v₀ = 0`, `h = 0,01`, `N = 10⁴` (t = 100 ≈ 15,9 періоду),
`E = (v² + ω²x²)/2`. Період міряємо за висхідними перетинами нуля (лінійна
інтерполяція між кроками), усередненими за весь прогін.

| інтегратор | очікування з теорії | перевірка | допуск |
|---|---|---|---|
| явний Ейлер | енергія множиться на `(1 + h²ω²)` кожен крок: після `N` кроків ≈ e¹ | `E` зростає на **кожному** кроці; `E_N/E₀` = `(1+h²)^N` | відносна похибка від формули ≤ 1·10⁻⁹; `E_N/E₀ − 1 > 0,5` |
| Ейлер–Кромер | зберігається модифікована енергія; `ΔE/E₀` коливається з амплітудою ≈ `hω/2` = 5·10⁻³, без дрейфу | `max ΔE/E₀` за весь прогін; огинаюча на кроках `9·10⁴…10⁵` проти `0…10⁴` | ≤ 1·10⁻²; огинаюча зросла ≤ 5 % |
| швидкісний Верле | амплітуда коливань `ΔE/E₀` ≈ `h²ω²/8` ≈ 1,25·10⁻⁵, без дрейфу | те саме | ≤ 1·10⁻⁴; огинаюча зросла ≤ 5 % |
| RK4 | не симплектичний: енергія **повільно спадає**, множник за крок `1 − h⁶/72 + h⁸/576` | `E_N/E₀ − 1` проти формули; знак — спад | абсолютна різниця з формулою ≤ 1·10⁻¹¹; `E_N < E₀` |

Період (теорія: `T₀ = 2π/ω`):

| інтегратор | очікувана відносна похибка періоду | допуск |
|---|---|---|
| явний Ейлер | `+h²/3` ≈ 3,3·10⁻⁵ | ≤ 1·10⁻⁴ |
| Ейлер–Кромер | `−h²/24` ≈ 4,2·10⁻⁶ | ≤ 1·10⁻⁴ |
| швидкісний Верле | `−h²/24` ≈ 4,2·10⁻⁶ | ≤ 1·10⁻⁴ |
| RK4 | ~`h⁴/120` ≈ 10⁻¹⁰ (плюс похибка лінійної інтерполяції перетину ~10⁻⁹) | ≤ 1·10⁻⁷ |

## 2. Задача Кеплера (площина, `GM = 1`)

Умови: `r₀ = (1, 0)`, `v₀ = (0; 1,2)` — еліпс (`E = −0,28`, `a ≈ 1,786`, `T ≈ 15,0`),
старт у перицентрі; `h = 10⁻³`, `N = 2·10⁴` (t = 20 > одного оберту).
Момент імпульсу `L = x·vy − y·vx`.

| інтегратор | теорія | допуск на `max |ΔL/L₀|` |
|---|---|---|
| швидкісний Верле | центральна сила дає поштовхи вздовж `r` → `L` зберігається точно (до округлення, ~N·ε) | ≤ 1·10⁻¹¹ |
| Ейлер–Кромер | те саме (поштовх уздовж `r`, дрейф уздовж нової `v`) | ≤ 1·10⁻¹¹ |
| RK4 | не зберігає `L` точно, похибка ~ локальна похибка методу | ≤ 1·10⁻⁶ |

Додатково для Верле: `max |ΔE/E₀|` ≤ 1·10⁻⁴ (амплітуда ~h²·(прискорення в перицентрі), очікувано ~10⁻⁶).

## 3. Кидок без опору

Умови: `v₀ = 20 м/с`, `α = 45°`, `g = 9,8 м/с²`, `h = 10⁻³ с`, інтегруємо до `t = 2,8 с`
(до падіння, `t_пад = 2v₀ sin α / g ≈ 2,886 с`).

| інтегратор | теорія | допуск |
|---|---|---|
| швидкісний Верле | точний для сталої сили (квадратична траєкторія) | `|r − r_точн|` ≤ 1·10⁻⁹ м |
| RK4 | точний для поліномів до 4-го степеня | `|r − r_точн|` ≤ 1·10⁻⁹ м |
| явний Ейлер | похибка першого порядку, у замкненій формі: `y_числ − y = +g·h·t/2`, `x` точний | відхилення від цієї формули ≤ 1·10⁻⁹ м |
| Ейлер–Кромер | `y_числ − y = −g·h·t/2`, `x` точний | відхилення від формули ≤ 1·10⁻⁹ м |

Дальність (Верле, точка падіння лінійною інтерполяцією між кроками) проти
`R = v₀² sin 2α / g`: ≤ 1·10⁻⁶ м. Лінійна інтерполяція параболи на кроці `h` дає
похибку ~`g h²/8` за висотою, тобто ~10⁻⁷ м за дальністю.
