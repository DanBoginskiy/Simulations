# KaTeX, вбудований у файли серії

`katex.inline.css` — офіційний CSS KaTeX 0.16.11, у якому `@font-face` замінено
на `data:`-рядки: вісім шрифтів (Main Regular/Bold/Italic, Math-Italic і чотири
Size для дужок та радикалів), урізані під ASCII, грецьку абетку й математичні
знаки. Решту дванадцять гарнітур — Fraktur, Script, SansSerif, Typewriter,
Caligraphic, AMS — викинуто: у формулах серії вони не трапляються.

Кирилиці KaTeX не має зовсім, тож українські слова у формулу не заходять: вони
лишаються звичайним HTML поруч. Це збігається з правилом брендбука — формула
символьна, одиниці й пояснення стоять після неї.

`build-fonts.py` відтворює цей CSS із офіційної збірки (потрібна мережа й
fontTools). `katex.min.js` — без змін.

Разом на один файл серії: 113 КБ CSS зі шрифтами + 275 КБ JS.
